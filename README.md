# 🎮 Lost Ark Raid Manager

**Современное десктопное приложение для управления рейдами и персонажами в Lost Ark**

## 🚀 **Возможности**

### **🎯 Управление рейдами**
- Создание и планирование рейдов
- Система регистрации участников
- Календарь рейдов с уведомлениями
- Отслеживание прогресса и наград
- Фильтрация по типу, статусу, серверу

### **👤 Управление персонажами**
- Детальная информация о персонажах
- Система экипировки и характеристик
- Калькулятор DPS и оптимизации
- Трекер прогресса и достижений
- Фильтрация по классу, серверу, уровню

### **💬 Многоканальный чат**
- Система каналов (общий, рейды, торговля, помощь)
- Управление пользователями и ролями
- Реакции и эмодзи
- Поиск и фильтрация сообщений
- Уведомления о новых сообщениях

### **🛠 Полезные инструменты**
- Калькулятор уровня предметов
- Конвертер валют Lost Ark
- Трекер рейдов и наград
- Генератор оптимальных билдов
- Планировщик апгрейдов

### **📊 Аналитика и статистика**
- Детальная статистика рейдов
- Анализ эффективности персонажей
- Графики прогресса и достижений
- Отчеты по активности
- Экспорт данных

## 📦 **Установка и запуск**

### **Предварительные требования**
- Node.js 16+ 
- npm или yarn
- Git

### **Клонирование репозитория**
```bash
git clone https://github.com/xSlowly343/Utom.git
cd Utom
```

### **Установка зависимостей**
```bash
npm install
```

### **Запуск в режиме разработки**
```bash
npm run dev
```

### **Сборка приложения**
```bash
npm run build
```

### **Запуск готового приложения**
```bash
npm start
```

## 🔧 **Конфигурация**

### **Настройки приложения**
- Путь к базе данных
- Настройки уведомлений
- Предпочтения темы
- Языковые настройки

### **Переменные окружения**
```bash
# Режим разработки
NODE_ENV=development

# Путь к базе данных
DB_PATH=./data/lost-ark.db

# Настройки Electron
ELECTRON_DEV_TOOLS=true
```

## 📱 **Использование**

### **Главная панель**
- Обзор статистики
- Быстрые действия
- Последние активности
- Уведомления

### **Управление рейдами**
1. Перейдите в раздел "Рейды"
2. Нажмите "Создать рейд"
3. Заполните информацию о рейде
4. Добавьте участников
5. Установите время и дату

### **Управление персонажами**
1. Откройте раздел "Персонажи"
2. Нажмите "Добавить персонажа"
3. Введите характеристики
4. Настройте экипировку
5. Сохраните изменения

### **Чат**
1. Выберите канал в левой панели
2. Введите сообщение
3. Используйте реакции и эмодзи
4. Настройте уведомления
